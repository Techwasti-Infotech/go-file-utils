go-file-utils

Production-grade, zero-dependency filesystem and file manipulation utilities for modern Go applications.

GitHub Repository Explore API Reference
🛡️
Zip Slip Protection
Active path sanitization on all archive extractions prevents path-traversal directory escape attacks.
💾
Atomic File Writes
Write safely via staged hidden files and atomic system renames to protect data from sudden crashes.
🔍
Advanced File Finder
Walk directory trees filtering with Glob, compiled Regex, extensions, size thresholds, and time windows.
📊
Progress-Tracked Streaming
Transfer large streams with bounded memory usage (64KB chunks) and real-time progress callbacks.
🔐
Streaming Checksums
Compute and verify MD5, SHA1, SHA256, and SHA512 hashes on files of any size without loading into RAM.
🔒
Process File Lock
Coordinate concurrent workers and processes with atomic sentinel file locks with configurable timeouts.

go get github.com/Techwasti-Infotech/go-file-utils

Core API Reference

Function Description
Exists(path) bool Check if a file or directory exists.
EnsureDir(path, perm) error Create directory and all missing parent folders.
CopyFile(src, dst, opts) error Copy file with timestamp preservation and overwrite protection.
WriteFileAtomic(path, data, perm) error Safe atomic write with disk sync and temp file replacement.
ReadLines(path, callback) error Stream lines one-by-one with early termination capability.
Zip(src, dstZip) / Unzip(zip, dstDir) Zip compression & extraction with Zip Slip vulnerability protection.
TarGz(src, dst) / UntarGz(tar, dstDir) Tar.gz compression & extraction with traversal guard.
FileSHA256(path) (string, error) Streamed computation of SHA-256 checksum in hexadecimal.
WithLock(path, timeout, fn) error Execute critical section under mutual exclusion file lock.
WithTempDir(prefix, fn) error Execute callback inside automatically cleaned temporary directory.
